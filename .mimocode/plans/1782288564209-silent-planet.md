# Aggiunta sezione note + metodo pagamento + report ordine PDF

## Contesto
L'ecommerce ha un carrello (CartPanel su desktop, CartDrawer su mobile). Serve aggiungere campi note/pagamento al carrello e generare un report PDF quando si preme "Procedi all'ordine".

## Dipendenza da aggiungere
- `jspdf` — generazione PDF client-side leggera (~180KB)

## File da modificare
- `src/App.tsx` — unico file da modificare

## Modifiche

### 1. Nuovi state in EcommercePage
```
notes: string          — testo note
paymentMethod: string  — metodo pagamento selezionato
showReport: boolean    — mostra pagina report
```

### 2. Aggiungere ai cart state di EcommercePage
- Passare `notes`, `paymentMethod`, `onNotesChange`, `onPaymentChange` a CartPanel e CartDrawer
- Aggiungere: textarea per note, radio/select per metodo pagamento (Mastercard, Visa, Amex, Bonifico SEPA, Assegno, Contanti)

### 3. Modificare CartPanel e CartDrawer
Aggiungere tra lista prodotti e totale:
- **Textarea** "Note per l'ordine" (placeholder: "Es. codice fornitore, indirizzo di consegna, riferimenti...")
- **Metodo di pagamento**: griglia di bottoni/badge cliccabili (uno attivo alla volta)
- Logica: questi campi vengono passati come props da EcommercePage

### 4. Pulsante "Procedi all'ordine"
Quando cliccato:
1. Imposta `showReport = true`
2. Il component EcommercePage rende `OrderReport` al posto dell'ecommerce

### 5. Nuovo componente `OrderReport`
Pagina full-screen con:
- Header con logo B2B + data ordine
- Tabella prodotti (nome, quantità, prezzo unitario, totale riga)
- Sezione note
- Metodo pagamento
- Totale generale
- Pulsante "Scarica il report da inviarci" → genera PDF con jspdf
- Pulsante "Torna all'ecommerce"

### 6. Funzione `generatePDF`
Usa jspdf per creare un PDF formattato:
- Header: logo B2B Group, data, numero ordine (random)
- Tabella prodotti
- Note
- Metodo pagamento
- Totale
- Download automatico come `ordine-b2b-group-{data}.pdf`

## Verifica
- `npm run lint` — nessun errore
- `npm run build` — build ok
- Test manuale: aggiungere prodotti → compilare note → selezionare pagamento → "Procedi all'ordine" → pagina report → "Scarica il report" → PDF scaricato
